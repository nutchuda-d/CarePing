# CarePing

ปุ่มเรียกผู้ดูแลสำหรับผู้ป่วยที่เคลื่อนไหวลำบาก: ผู้ป่วยกดปุ่ม IoT → backend ไล่แจ้งผู้ดูแลตามลำดับ → ผู้ดูแลรับทราบในแอปมือถือ

## โครงสร้าง

| โฟลเดอร์ | คืออะไร | ภาษา |
| --- | --- | --- |
| `packages/shared` | type และข้อตกลง MQTT ที่ทุกส่วนใช้ร่วมกัน | TypeScript |
| `packages/backend` | MQTT broker + escalation engine + REST/WebSocket API + ฐานข้อมูล | TypeScript (Node.js) |
| `packages/simulator` | ปุ่มจำลองบนเว็บ ใช้แทนปุ่มจริงระหว่างพัฒนา | HTML/JS |
| `packages/app` | แอปผู้ดูแล | TypeScript (React Native + Expo) |
| `firmware` | โค้ด ESP32 (ยังไม่เริ่ม) | C++ |

ช่วงพัฒนา **ทุกอย่างรันในเครื่องตัวเอง** ไม่ต้องสมัครบริการคลาวด์: MQTT broker (Aedes) และ PostgreSQL (PGlite) ฝังอยู่ใน backend ข้อมูลเก็บที่ `packages/backend/.data/`

## เริ่มใช้งาน (Windows / PowerShell)

```powershell
npm install            # ครั้งแรกครั้งเดียว ที่โฟลเดอร์ CarePing
npm run backend:fast   # รัน backend แบบเร่งเวลา 10 เท่า (ไว้ทดสอบ)
```

เปิด http://localhost:3000/simulator/ จะเห็นปุ่มจำลอง 5 ปุ่ม

เปิดอีกหน้าต่าง PowerShell แล้วรันแอป:

```powershell
npm run app
```

สแกน QR ด้วยแอป **Expo Go** บนมือถือ (มือถือกับคอมต้องต่อ Wi-Fi เดียวกัน) แล้วเลือกผู้ดูแลที่จะทดสอบ

> ครั้งแรกที่รัน Windows อาจถามเรื่อง Firewall ให้กด **Allow** สำหรับ Private network ไม่อย่างนั้นมือถือจะต่อ backend ไม่ได้

## คำสั่งอื่น

| คำสั่ง | ทำอะไร |
| --- | --- |
| `npm run backend` | รัน backend เวลาจริง (รอคนละ 2 นาที) |
| `npm test` | รันเทสต์ escalation engine |
| `npm run typecheck` | เช็ก type ทุก package |
| `npm run reset-db -w @careping/backend` | ล้างฐานข้อมูลกลับเป็นข้อมูลตั้งต้น |

## ข้อมูลตั้งต้น

- ผู้ป่วย: คุณยาย · ปุ่ม `btn-001`
- ผู้ดูแลตามลำดับ: ลูกคนโต (แอดมิน) → ลูกคนรอง → หลาน

## ลองทดสอบอะไรได้บ้าง

| ทดสอบ | ทำยังไง | ผลที่ควรเห็น (โหมด fast) |
| --- | --- | --- |
| ไล่ตามลำดับ | กดปุ่ม "ห้องน้ำ" แล้วไม่ต้องตอบ | ลูกคนโต → 12 วิ → ลูกคนรอง → หลาน → แจ้งทุกคน 3 รอบ → LED แดง |
| รับทราบ | กด "รับทราบ" ในแอป | LED ปุ่มเป็นสีเขียว หยุดแจ้งคนอื่น |
| ฉุกเฉิน | กดค้างปุ่มฉุกเฉิน 2 วิ | แจ้งทุกคนพร้อมกัน รวมคนที่อยู่นอกบ้าน |
| กดซ้ำ | กดปุ่มเดิมรัว ๆ | ไม่แจ้งซ้ำ นับจำนวนครั้งในเคส |
| สัญญาณหาย | ติ๊ก "ตัดสัญญาณ" ในปุ่มจำลอง | ~18 วิ แอปแจ้ง "ปุ่มขาดการเชื่อมต่อ" |
| กดตอนออฟไลน์ | ตัดสัญญาณแล้วกดปุ่ม แล้วต่อใหม่ | มีเสียงบี๊บ แล้วส่งเคสพร้อมป้าย "ส่งล่าช้า" |
| แบตต่ำ | เลื่อนแบตต่ำกว่า 20% | แอดมินได้รับแจ้ง |

## ยังไม่ได้ทำ (milestone ถัดไป)

- Push notification ตอนแอปปิด (ต้องใช้ development build ไม่ใช่ Expo Go)
- ระบบล็อกอินจริง (ตอนนี้เลือกผู้ใช้จากรายชื่อ)
- หน้าตั้งค่าแอดมินในแอป (API มีแล้ว: `PUT /api/caregivers/order`, `PUT /api/buttons/:n`)
- Export PDF สำหรับหมอ
- หน้าตาแบบ Liquid Glass ตามแบบใน Figma
- Firmware ESP32
